# Trong Cuong Tran | Academic Portfolio

A static academic site adapted from [Minimal Light](https://github.com/yaoyao-liu/minimal-light), with English, Vietnamese and Simplified Chinese content and a light/dark toggle. See `LICENSE-Minimal-Light` for the upstream licence.

## Edit and preview

- Edit English text and profile links in `index.html`.
- Edit translations and preference controls in `assets/site.js`.
- Edit the theme in `assets/site.css`.
- Replace `assets/Trong_Cuong_Tran_CV.pdf` to update the downloadable website CV.

Run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000`.

## Deploy on GitHub Pages

Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save. The `.nojekyll` file lets GitHub serve the static files directly. [GitHub Pages setup and plan requirements](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
